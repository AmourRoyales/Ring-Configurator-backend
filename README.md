# Jeni Diam ring studio API

Vercel functions for the Shopify ring configurator's story journey. They call OpenRouter using a free model.

Generated by `tools/ring-configurator/export-backend.mjs` in the Shopify theme repository.
Edit the backend there and re-export; edits made here are overwritten.

## Vercel

Import this repository with the default settings (Framework Preset "Other", no build command).
Add these environment variables for Production (and Preview, if used):

| Variable | Value |
| --- | --- |
| `OPEN_ROUTER_KEY` | OpenRouter API key (server-side only) |
| `RING_ALLOWED_ORIGINS` | `https://www.jenidiam.com,https://jenidiam.com,https://gwahb1-hf.myshopify.com` |
| `OPEN_ROUTER_MODEL` | Optional; defaults to `nvidia/nemotron-3-super-120b-a12b:free` |
| `OPEN_ROUTER_REASONING` | Optional; `low` by default |

Redeploy after changing variables.

Only model IDs ending in `:free` (or `openrouter/free`) are accepted. Routing
has a zero-price ceiling for prompt, completion and request fees; paid model
fallback and automatic retries are disabled. OpenRouter free quota and availability
still apply. The active backend ignores Gemini and Vertex credentials.

## Endpoints

- `GET /api/ring/health` reports the provider, the model and whether a key is set. It never calls the model.
- `POST /api/ring/recommend` with `{"text":"…"}` returns two or three validated ring designs.
  Only browsers on a listed origin are accepted. This blocks other websites; it is not authentication.
